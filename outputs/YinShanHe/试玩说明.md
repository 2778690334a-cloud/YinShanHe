# 一印山河 · 青绿画境 0.5

打开 `index.html` 或双击 `打开试玩.cmd`。完整解压后保留全部 JS 文件、`vendor` 和 `assets` 目录，可离线运行。使用支持 WebGL 的 Edge / Chrome。

现在首先进入「青绿画境」。拖动环视、滚轮缩放，或使用方向键与 + / - 键。可「缓缓游览」「回到此景」「留一帧」；「返回印台」进入原来的套印体验。套印过程中，顶部「青绿画境」可随时进入，返回后继续原进度。打开图片预览时 Esc 只关闭预览。

本轮将前景改为连续山体，增加展开的山脚、斜坡和高低山肩；寺院移到较低、较薄的山腰台地，两段低处山道外移，避免从寺院台基下方切过。修复基础与铺地顶面重合造成的闪纹，移除规则水纹和交叠的透明雾片，增加台基侧面与底部支撑检查。

画境现在按模型实际投影范围和屏幕中的控件位置自动取景。拖动可环视，滚轮／加减号仍可主动拉近查看细节；「回到此景」恢复完整构图。默认静止展示，点击「缓缓游览」才会自动转动。

默认使用「画质 · 高清」，可切换到「画质 · 流畅」。高清会提高实际画布分辨率，近看石缝、瓦垄与栏杆时更清楚；设备负载较高时可选流畅。两档保留相同的三维模型。美术参考、生成材质来源及完整提示词见 `画风参考与制作记录.md`。

## 怎么玩

1. 点击「入坊 · 开始套印」。纸张后边固定在夹纸横梁上。
2. 拖动木版套准，或使用方向键微调、辅助套准。浅色标记与红色辅助角标重合后，点击「开始上墨」。
3. 按住拖动棕刷，给露出的木版上墨。达到90%后可「覆纸」，也可「自动上墨」。
4. 等待纸张落下，拖动元宝形上刷刷纸背。达到90%后可「揭纸」，也可「自动刷印」。
5. 依次完成山形、林影、人家三版。每一版的上墨和压印分别计数。
6. 完成后拖动环视山河、滚轮缩放。「保存画面」预览场景PNG；「山河入纸」后可「保存印稿」。预览中点击「下载 PNG」，或长按／右键保存图片。内嵌浏览器下载落盘尚未确认，详见验证记录。

顶部「器物细看」切到棕刷、上刷和刻刀的特写，内附资料链接。进入特写会暂停印台动作，返回后继续。顶部「重新开始」清空当前进度。

「声音」开启合成雨声和提示音。体验不需要账号，不上传数据；只有主动点击外部资料链接时才访问相应网站。

## 保留的器物与工序

- 上墨棕刷：散开的棕丝、束扎刷身、绑绳与短柄。
- 元宝形上刷：两端翘起的棕纤维、木芯、缠绳和紧绳木签。
- 四把木柄刻刀：区分平刃与弧口，增加金属箍与刀面。
- 三块雕版：从三版原创印稿生成左右镜像的凸起纹样，去除无关装饰线。
- 印台：固定夹纸横梁、螺杆、侧框、台面开槽和槽下纸叠。
- 交互：移版套准 → 上墨 → 覆纸 → 刷纸背 → 揭纸。纸张绕固定后边弯曲翻动，刷具跟随操作落点。

## 参考与表达范围

器物参考：[哈佛艺术博物馆2016年荣宝斋工坊实拍](https://www.harvardvisualchina.com/rongbaozhai-workshop)。参考其中棕刷、刻刀、印台、夹纸与过纸槽的形态和关系。

上刷结构参考：[中国非物质文化遗产网·上刷](https://www.ihchina.cn/printing_tool_detail/25930.html)。

基本工艺参考：[中国非物质文化遗产网·木版水印](https://www.ihchina.cn/project_details/14406.html)。

这些是依照片和文字资料制作的程序化简模，并非实物扫描或按测量尺寸复刻；未将外部照片作为贴图打包。纸张翻动是参数动画，未模拟纸纤维、摩擦或台槽中的真实走纸。纸背透墨、90%完成阈值、自动补全余墨和红色套准角标都是交互辅助；三色与图案分版用于体验，真实木版水印可能需要更多分版与印次。最终山河升起是艺术演绎。

程序图形、模型和合成音频由本次AI协作生成。岩壁设色贴图使用内置 image_gen 生成，保存在 `assets/qinglu-cliff-albedo.png`；为兼容直接打开本地网页，同时提供内嵌数据副本。Three.js 0.160.1采用MIT许可证，见 `vendor/THREE-LICENSE.txt`。

## 工程状态

当前可运行成品是 Three.js 浏览器样机。随附 `YinShanHe-UE` 是此前的原生UE C++源码草稿，尚未编译、运行或打包；器物、工序和本轮青绿画境均在浏览器版实现，不能视为已完成的UE参赛工程。三维画境是新的美术方向习作，尚需进一步统一二维印稿与立体场景细节。
